# CRISPR Analysis Utils

Reusable Python utilities for CRISPR screen analysis, preprocessing,
plotting, and downstream workflows.

This repository is designed for shared lab utilities:

- installable functions for collaborators
- docstrings close to the code
- rendered GitHub Pages documentation with examples and parameters
- lightweight tests for every helper

## First utilities

The initial package includes `counts_per_million()`. Use it as a template for
future functions: include a compact example, clear parameter
descriptions, and a focused test.
